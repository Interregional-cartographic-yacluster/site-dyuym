# Медиашкола «ДЮйМ»

Главная страница медиашколы Центра детского творчества Курска. Сайт статический: сборка и установка зависимостей не нужны.

## Локальный запуск

Откройте `index.html` в браузере или запустите из корня репозитория локальный сервер:

```sh
python3 -m http.server 8000
```

Карта загружается с Яндекс Карт и для её отображения нужен интернет. Если карта недоступна, на странице остаются адрес и ссылка на неё.

## Структура

- `index.html` — содержание главной страницы и навигация по её разделам.
- `styles.css` — оформление и адаптация для разных экранов.
- `script.js` — раскрытие меню на небольших экранах; без JavaScript ссылки навигации также доступны.
- `CNAME` — домен для публикации из ветки GitHub Pages.
- `.nojekyll` — публикация статических файлов без обработки Jekyll.
- `assets/` — изображения, шрифты, иконки и их лицензии.

Проверить ссылки навигации, текст подвала и локальные ресурсы можно командой:

```sh
python3 -m unittest discover -s tests
```

## Публикация на GitHub Pages

1. В настройках организации GitHub в разделе **Pages** рекомендуется подтвердить владение доменом `cdtkursk-dyuym.ru`, добавив предложенную GitHub TXT-запись в DNS. Это защитит домен и его поддомены от захвата. Подробности — в [документации GitHub](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/verifying-your-custom-domain-for-github-pages).
2. В настройках репозитория **Settings → Pages** включите публикацию **Deploy from a branch**, выберите ветку с сайтом и каталог `/ (root)`. В поле **Custom domain** должен быть указан `www.cdtkursk-dyuym.ru`. Файл `CNAME` содержит то же имя. Домен необходимо добавить в GitHub Pages **до изменения DNS**.
3. В панели REG.RU откройте домен → **DNS-серверы и управление зоной → Изменить**. Удалите существующие A/AAAA-записи для `www`, если они есть, и добавьте запись:

   | Тип | Поддомен | Каноническое имя |
   | --- | --- | --- |
   | CNAME | `www` | `interregional-cartographic-yacluster.github.io` |

   Имя указывается без `https://` и без пути к репозиторию. Другие DNS-записи, в том числе MX и TXT, менять не нужно. [Инструкция REG.RU по настройке записей](https://help.reg.ru/support/dns-servery-i-nastroyka-zony/nastroyka-resursnykh-zapisey-dns/nastroyka-resursnykh-zapisey-v-lichnom-kabinete).
4. После обновления DNS дождитесь выпуска сертификата и включите **Enforce HTTPS** в настройках Pages, когда переключатель станет доступен. Проверяйте именно `https://www.cdtkursk-dyuym.ru/`.

Если публикация временно настроена из рабочей ветки, после её объединения с `main` переключите источник Pages на `main` **до удаления рабочей ветки**.

Адрес без `www` не перенастраивается описанными действиями. Если он тоже должен открывать сайт, отдельно замените его A-запись на четыре адреса GitHub Pages: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`. При корректных записях для обоих имён GitHub Pages перенаправит домен без `www` на основной адрес с `www`. Не удаляйте другие типы записей домена. Подробности — в [документации GitHub](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site).

## Старый сайт на Google Сайтах

Google Сайты не позволяют настроить обычное серверное перенаправление с адреса `sites.google.com`. После запуска нового домена владелец старого сайта может открыть редактор и выбрать **Настройки → Баннер с уведомлением → Показать баннер**. Текст баннера: **«Мы переехали на новый сайт»**; надпись на кнопке: **«Перейти на новый сайт»**; ссылка: `https://www.cdtkursk-dyuym.ru/`. Затем нужно нажать **Опубликовать**. Это ссылка, требующая нажатия, а не автоматический редирект. [Инструкция Google](https://support.google.com/sites/answer/9826219?hl=ru).
